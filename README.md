# MIRA — página de instalação

Página pública (GitHub Pages) que coloca o **MIRA** na tela inicial do celular com o ícone próprio.
Endereço: https://caroljncastro.github.io/mira-app/

O app (`app.html`) é montado a partir do repositório privado `mira` (`tools/montar-pagina.js`) e fala com o
servidor do MIRA no Supabase. Esta página tem o app, o ícone e o manifesto. Não contém dados de alunos, senhas ou chaves.
