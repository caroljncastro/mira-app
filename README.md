# MIRA — página de instalação

Página pública (GitHub Pages) que coloca o **MIRA** na tela inicial do celular com o ícone próprio.
Endereço: https://caroljncastro.github.io/mira-app/

O app em si continua no Google Apps Script (repositório privado `mira`). Esta página só tem o ícone,
o manifesto e uma moldura que abre o app. Não contém dados de alunos, senhas ou chaves.
